# 찾아가는 AX교실 ‘어, 이게되네?’

중랑구청 AI혁신팀이 만든 유튜브 큐레이션 AX 교육 사이트와, 같은 사이트를 다시 짓거나 다른 대상용으로 복제하는 Claude 스킬입니다.

> 사과 속 씨앗은 셀 수 있지만, 씨앗 속 사과는 셀 수 없다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `SKILL.md` | 스킬 본문. 큐레이션 원칙, 영상 찾는 절차, 사이트 구성, 데이터·권한, 게시·확인 순서 |
| `template/index.html` | 사이트 원본(Claude 아티팩트용, 문서 골격 없이 본문만) |
| `template/capabilities.json` | 아티팩트 게시 때 넘기는 런타임 권한(db 규칙, user, downloads) |

## 사이트 한눈에

- 성장 5단계: 씨앗 → 새싹 → 줄기 → 나무 → 열매, 단계마다 결과물을 만드는 미션 하나와 10분 이하 실습 영상 4~5편
- 업무 상황별 영상, 중랑 AI 레시피 서랍(‘이렇게 시켰어요’ 복사, ‘이게되네!’ 반응, ○월의 레시피)
- 누가누배 묻고 답하기(영상·단계별 질문, 베스트 답, FAQ 승격)
- AI혁신팀 검수함(인증·추천 승인/보완 요청)
- 배지를 받은 단계의 동료 자료 추천, 다섯 단계 수료 시 수료증 PNG 내려받기

## 원칙

강의를 만들지 않고 고르고, 듣게 하지 않고 만들게 하고, 강사 대신 동료가 가르친다(편집형 교육 · 에듀레이션). 쌓인 레시피가 검수를 거쳐 행정의 기본기가 되는 것(레시피 행정)이 목표입니다.

## 쓰는 법

Claude에게 “AX교실 사이트 만들어 줘”, “골목 교실 버전으로 복제해 줘”처럼 요청하면 `SKILL.md`를 따라 작업합니다. 직접 게시하려면 `template/index.html`을 Claude 아티팩트로 올리고 `template/capabilities.json`을 권한으로 지정하세요.

영상 목록은 제목·채널·조회수로 고른 후보입니다. 운영 전에 팀이 직접 보고 확정해 주세요.

## 연계 (밸류체인)

이 저장소는 [policy-media-desk](https://github.com/goodmorninghope-khs/policy-media-desk) 밸류체인의 **⑤ 학습** 고리다. 상태: 제안 (발행인 확인 후 실제로 이으면 '연계'로 바꾼다).

- 받음: WEEKLY AX 신호 → AX교실 '업무 상황별' 사례·미션 후보
- 넘김: 교실에서 나온 현장 질문 → 촉 레이더·JUNGNANG Q 후보
- 넘길 때는 출처 지면(지면명·호수·날짜·링크)과 '닿는 공약'을 붙이고, 침은 의견으로 남긴다. 결정은 받는 고리의 책임자가 한다.
